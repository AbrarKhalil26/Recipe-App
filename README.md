# 🍲 Recipe App
A modern recipe web application that allows users to discover, search, and save their favorite meals with a clean UI and smooth experience. Built with React.js and powerful libraries for state management, API integration, and responsive design.

### Lives: https://abrarkhalil26.github.io/Recipe-App/

### 📌 Project Description
This application enables users to:
- Browse a wide collection of recipes.
- Search recipes by name or category.
- View detailed recipe information (ingredients, instructions, etc.).
- Add/remove recipes to/from favorites (wishlist).
- Manage recipes with filtering and pagination.
- Print recipes directly for offline use.
- Enjoy a responsive and modern UI on all devices.

### 🚀 Features
- Recipe browsing and detailed recipe pages
- Search and filtering functionality
- Add/remove recipes to favorites
- Pagination for large recipe collections
- Rating system for recipes
- Form handling with validation
- Real-time notifications for user actions
- Print recipes easily with one click
- Fully responsive and modern UI

### 🛠 Tech Stack
- React.js 18 – Core UI library
- React Router DOM – Navigation and routing
- Redux Toolkit + React Redux – State management
- React Query – Data fetching and caching
- Axios – API requests
- Firebase – Authentication & storage
- React Hook Form + AJV – Form handling and validation
- Tailwind CSS + Styled Components – Styling and responsiveness
- React Icons & @smastrom/react-rating – Icons and rating system
- React Paginate – Pagination UI
- React Toastify – Notifications
- React To Print – Print recipe functionality
- EmailJS – Contact form email handling

### 📡 API / Data
- Fetch recipes and categories using API integration (Axios + React Query).
- Handle authentication and data persistence with Firebase.
- Local state management for wishlist, favorites, and cart-like features.
- API-Link: https://rapidapi.com/apidojo/api/tasty/
